# Cloudflare D1 datasource

Query Cloudflare D1 databases from Grafana dashboards using SQL. Requires Grafana 10.4.0 or later.

Add a Cloudflare D1 datasource under **Connections → Data sources**. Enter your Cloudflare account ID, database ID and an API token with D1 read access. Choose **Save & test**, then select the datasource in a panel and enter a SQL query.

See the [installation and configuration guide](https://github.com/olipayne/grafana-cloudflare-d1-datasource#setup--configuration) for details.
